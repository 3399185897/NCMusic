## 三、详细版（用于 GitHub Release / 博客 / 更新日志归档）

### v1.1.0 · 2026-10-08

本次更新聚焦**视觉与手感**，同时修复了若干影响观感与操作的问题。

#### 🧩 歌单墙：正方形无缝拼接

歌单区迎来一次彻底重做。原本平均分割的网格，换成由 **18 个大小不一的方块**
紧密拼接而成的**正方形无缝墙** —— 所有方块无缝衔接、互不重叠，
最终恰好铺满一个 3:2 的完整矩形，形成类似现代专辑拼贴墙的艺术效果。

整体采用统一大圆角容器，内部方块不带各自圆角，观感是一个整体而非散落卡片。
该拼接方案经过逐像素校验，确保任何屏幕宽度下都严格无缝。

同时，歌单墙的数据源接入了**私人雷达**，并安置于视觉最醒目的大方块上；
其余位置由推荐歌单自动补齐并按 id 去重，杜绝封面重复。

#### 🎨 Material 3 设计规范

- **滑块**：改为带停靠点的分段轨道，轨道上等距排布圆点。
  同时把数值吸附交给控件本身处理，彻底解决了「拖动位置与显示数值不同步」的老问题。
- **开关**：采用 Material 3 的角色配色，未选中态为描边样式，状态区分更清晰。
- **加载指示器**：增加可见轨道与圆角线帽，更贴合规范。
- **分组卡片**：更换为 Material 3 的容器色阶，明暗层次更准确。

#### ⚙️ 播放体验

- 播放器改为**同树覆盖层**，展开与收起为整页平滑位移动画，不再走页面路由转场，
  显著降低了打开和关闭时的开销。
- 收起播放器时，底部悬浮岛会同步淡入并轻微上移，衔接自然。
- 修复了关闭播放器瞬间偶发的画面跳变。

#### 🐛 问题修复

1. 歌单墙封面重复（数据源不足 18 条时循环取用）
2. 缓存大小滑块的刻度标签与数值位置错位
3. 听歌统计页卡片因文案过长而高度不一
4. 播放器背景透出下层页面、底部导航栏遮挡播放器
5. 悬浮岛关闭时因组件重建导致的取色闪变

#### 📦 安装

下载 `NCMusic-v1.1.0-release.apk` 直接安装，需 Android 8.0 及以上。
